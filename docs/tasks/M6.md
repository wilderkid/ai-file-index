# M6 — IPC + Windows 服务

## 目标
`aifi-service.exe` 作为 Windows 服务运行：启动时为所有 NTFS 固定卷建立索引（快照优先），后台跟踪 USN，
在命名管道 `\\.\pipe\ai-file-index` 上处理 `aifi-protocol` 请求，只允许本机授权用户连接。

## 背景
- 骨架：`crates/aifi-service/src/main.rs`（`define_windows_service!`，`service_main` / `serve_pipe` 为 `todo!`；非 Windows 打印提示退出）、
  `handler.rs`（`Handler::handle`：`Hello` 版本检查已实现，其他请求 `todo!("M6: …")`）。
- 协议：`aifi-protocol`（`PROTOCOL_VERSION = 1`，JSON lines，帧 ≤ 4 MiB，`RequestEnvelope{id, method, params}` /
  `ResponseEnvelope{id, type, data}`，`ErrorCode`，`clamp_limit`）。
- 依赖：`windows-service 0.8.1`、`tokio 1.54.1`（`net::windows::named_pipe`）、`windows 0.62.2`（安全描述符、令牌）。
- 线程模型建议：每卷 1 个 USN 阻塞线程 → `RwLock<VolumeIndex>` 写；查询走 tokio 任务、短持读锁；快照定时任务。

## 要改的文件
- `crates/aifi-service/src/main.rs`、`win/` 子模块（新）：服务生命周期（Start/Stop/Shutdown/Preshutdown）、卷管理、快照调度。
- `crates/aifi-service/src/handler.rs`：5 个请求的实现（基于 M4 `search`、M5 `ProjectRegistry` / `walk_tree`）。
- `crates/aifi-service/src/recent.rs`（新）：`recent_changes` 环形缓冲（每卷 N=10k 条，已过滤黑名单）。
- `crates/aifi-service/src/pipe.rs`（新）：命名管道服务器、DACL、客户端身份。
- `crates/aifi-protocol`：如需新增字段，`#[serde(default)]`。

## 接口
```rust
pub struct ServiceState { volumes: Vec<VolumeSlot>, projects: RwLock<ProjectRegistry>, recent: RecentLog, started: Instant }
impl Handler { pub fn handle(&self, req: Request, caller: &CallerInfo) -> Response; }
pub struct CallerInfo { pub pid: u32, pub user_sid: String, pub is_admin: bool, pub profile_dir: Option<String> }
#[cfg(windows)] pub async fn serve_pipe(state: Arc<ServiceState>, shutdown: CancellationToken) -> anyhow::Result<()>;
```

## 验收标准 / 测试
- [ ] `Handler` 单元测试（Linux 可跑，用假卷构造 `ServiceState`）：5 种请求的正常与错误路径；版本不符 → `VersionMismatch`；
      超大帧 → `FrameTooLarge`；非法 JSON → `BadRequest` 且连接不中断。
- [ ] 结果按调用方过滤：非管理员看不到其他用户 profile 下的条目。
- [ ] 管道 DACL：SYSTEM、Administrators、交互式用户允许；`NETWORK` 拒绝；使用 `FILE_FLAG_FIRST_PIPE_INSTANCE`。
- [ ] Windows CI（`windows-latest`）：以控制台模式（`--console` 参数，非服务）在 VHD 上启动，跑一个协议往返集成测试。
- [ ] 服务停止时写快照并在 5 s 内退出；USN 线程收到 `JournalReset` 时只重建该卷，查询继续可用。
- [ ] `index_status` 报告每卷条目数、状态（building/ready/rebuilding/error）、内存、最后 USN 时间。

## 不在范围内
MCP（M7）、安装包（M7）、内容搜索。

## 审查清单
- [ ] 不监听任何 TCP/UDP 端口；不发起网络请求；不执行外部命令
- [ ] 管道 ACL 与客户端身份校验有代码注释说明威胁模型
- [ ] 锁持有时间短，查询不会被 USN 写阻塞超过 50 ms
- [ ] 所有请求都有大小 / 条数上限
- [ ] 开发者本机测试使用 `--console` 模式与 VHD，未在开发机安装服务（除非人类明确同意）
- [ ] PR ≤ ~400 行（handler / pipe / service 生命周期 / recent 分开）
