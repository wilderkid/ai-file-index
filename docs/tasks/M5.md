# M5 — 项目层（项目根、.gitignore、黑名单、排序）

## 目标
让结果"懂项目"：默认只搜当前项目、尊重 `.gitignore`、跳过 `node_modules` 等、永远隐藏敏感文件、当前项目结果排最前；
支持 `list_projects` 与 `list_project_tree`。

## 背景
- 骨架 `aifi-project`：`ROOT_MARKERS`（`.git`、`Cargo.toml`、`package.json`、`pyproject.toml`、`go.mod`、`*.sln` 等）、
  `DEFAULT_EXCLUDED_DIRS`、`detect_root(start, list_dir)`（最近者优先，盘符根保留 `\`）、`is_within`（大小写不敏感）、
  `RankTier` / `rank_tier`、`Denylist`（默认目录与文件 glob，见 `docs/privacy.md`）。`GitignoreFilter` 是 `todo!("M5")`。
- `aifi-project` **不读盘**：目录列表由调用方（服务，基于索引）提供；`.gitignore` 内容由服务读取后传入
  （这是 v1 唯一需要读的文件内容，只读、仅限项目根下的 `.gitignore` / `.git/info/exclude`）。
- 依赖：`ignore 0.4.34`（`gitignore::GitignoreBuilder`）、`globset 0.4.21`。

## 要改的文件
- `crates/aifi-project/src/lib.rs`：`GitignoreFilter`（从内容构建，支持嵌套 `.gitignore`、否定规则）、`ProjectRegistry`。
- `crates/aifi-project/src/denylist.rs`：支持从配置追加（只能追加，不能删除内置项）。
- `crates/aifi-project/src/tree.rs`（新）：树遍历规则（深度、条目上限、过滤顺序）。
- `crates/aifi-query/src/lib.rs`：把 `QueryContext.gitignored` 接到 `GitignoreFilter`。
- `crates/aifi-harness/tests/project.rs`（新）：嵌套 monorepo、子模块、`.sln` 仓库。

## 接口
```rust
impl GitignoreFilter {
    pub fn from_contents(root: &str, files: &[(String /*目录相对路径*/, String /*内容*/)]) -> Result<Self, ignore::Error>;
    pub fn is_ignored(&self, rel_path: &str, is_dir: bool) -> bool;   // 含父目录匹配
}
pub struct ProjectRegistry { /* root -> Project, 最近访问时间 */ }
impl ProjectRegistry {
    pub fn discover(idx: &VolumeIndex) -> Self;                         // 扫描索引中的根标记
    pub fn resolve(&self, cwd: &str) -> Option<&Project>;
    pub fn list(&self, filter: Option<&str>, limit: usize) -> Vec<&Project>;
}
pub fn walk_tree(idx: &VolumeIndex, root: NodeId, opts: &TreeOptions, deny: &Denylist, gi: Option<&GitignoreFilter>) -> Vec<TreeEntry>;
```

## 验收标准 / 测试
- [ ] 嵌套项目：`C:\mono\packages\web` 内的 cwd 解析到 `web`（有 `package.json`），而不是 `mono`。
- [ ] `.gitignore`：`target/`、`*.log`、`!keep.log`、子目录 `.gitignore`、以 `/` 开头的锚定规则。
- [ ] `include_ignored=true` 时显示 gitignored 与默认排除项，但**黑名单项永不显示**（专门测试）。
- [ ] 排序：同名文件在当前项目 > 其他项目 > 用户目录 > 其他。
- [ ] `walk_tree` 遵守 `max_depth`、条目上限，并返回 `truncated` 标志。
- [ ] 配置追加的黑名单生效；尝试删除内置项无效。

## 不在范围内
IPC 与服务（M6）、监视 `.gitignore` 变化的细节（M6 时通过 USN 事件触发重载即可）。
