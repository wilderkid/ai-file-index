# M4 — 拼音 + 查询引擎

## 目标
`find_files` 背后的查询引擎达到生产质量：子串 / 前缀 / 拼音全拼 / 首字母 / 中英混合 / glob / 正则 / 模糊匹配，
200 万条目 p50 < 20 ms、p99 < 100 ms，排序符合直觉。

## 背景
- 骨架：`aifi-pinyin`（`readings`、`keys_for`、`mixed_match`，多音字每字最多 3 个读音，组合上限 4）；
  `aifi-query`（`QuerySpec` → `CompiledQuery::compile`、`match_name`、`search_volume`、`QueryContext`、`PostProcessor`、分数表
  Exact 100 > Prefix 80 > Substring 60 > Pinyin 55 > Glob/Regex 50 > Fuzzy 30，项目分层加分 40/20/10/0）。
  `fuzzy` 分支是 `todo!("M4: …")`。
- 用户需求：中文文件名必须支持拼音与首字母（`jdbg` → `季度报告.docx`，`季度bg`、`jidu报告` 也要命中）。
- 依赖：`pinyin 0.11.0`（heteronym）、`nucleo-matcher 0.3.1`、`globset 0.4.21`、`regex 1.13.1`、`rayon 1.12.0`、`memchr 2.8.3`。

## 要改的文件
- `crates/aifi-pinyin/src/lib.rs`：预计算 `PinyinKeys` 缓存（只对含汉字的名字，约占总数 <5%）。
- `crates/aifi-query/src/lib.rs`：fuzzy、并行扫描、大小写折叠快路径（ASCII 用 memchr/memmem）、正则大小与超时上限、稳定排序与游标分页。
- `crates/aifi-core/src/index.rs`：如需，增加"名字小写副本"或"含汉字"标志位（与 M1 协调）。
- `crates/aifi-query/benches/`（可选）。

## 验收标准 / 测试
- [ ] 拼音：`jdbg`、`jidubaogao`、`季度bg`、`jidu报告`、多音字（`银行`=yinhang，`行动`=xingdong）、带数字/扩展名（`jdbg2024`）。
- [ ] 模糊：`mcrs` 命中 `main_core.rs`；分数低于子串命中。
- [ ] Auto 模式：含 `*`/`?` → glob；以 `re:` 开头 → regex；否则子串 + 拼音 + 模糊兜底。
- [ ] 正则超过 1 MiB 编译大小 → `QueryError::BadRegex`；`limit` 被 `clamp_limit` 截到 1000。
- [ ] 同分时排序稳定（路径短者优先，再按字典序），游标翻页不重复不遗漏。
- [ ] 隐私黑名单与默认排除测试仍全部通过（`include_ignored=true` 也不能看到 `.ssh`）。
- [ ] 基准：`synthetic(2_000_000)` 上子串、拼音、模糊各 100 次查询的 p50/p99，贴到 PR。
