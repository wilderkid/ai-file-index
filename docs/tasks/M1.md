# M1 — 核心索引 + 假卷测试框架

## 目标
把 `aifi-core` 的内存索引做成**正确、紧凑、可测**的生产级实现，并把 `aifi-harness` 扩展成后续所有里程碑的测试地基。
完成后：任何 `VolumeSource` 都能 `build_index` → `apply` 增量 → 拼出正确全路径，且 200 万条目内存 < 200 MB。

## 背景
- 本项目是 Windows 本地文件名索引服务（见 `docs/architecture.md`）。真实数据来自 NTFS（M2），但索引逻辑与平台无关。
- 骨架已提供：`StringArena`、`VolumeIndex`（`Vec<Node>` + `HashMap<FileRef, NodeId>`）、`VolumeSource` / `SnapshotStore` trait、
  `build_index` / `catch_up`，以及 `FakeVolume`（倒序枚举，模拟子先于父）。现有 6 + 5 个测试通过。
- NTFS 语义要点：FRN（64 位，含序号）唯一标识文件；父目录用父 FRN 表示；根目录 FRN 低 48 位 = 5；
  硬链接 = 同一 FRN 多个 (parent, name)；枚举顺序不保证父先于子。

## 要改的文件
- `crates/aifi-core/src/arena.rs`：垃圾整理 `compact()`，重映射 `NameRef`。
- `crates/aifi-core/src/index.rs`：可选元数据（size、mtime、attributes）；`compact()`；按名字小写缓存（为查询加速）；
  硬链接（v1 可只保留第一个链接并记录 TODO，需测试明确行为）。
- `crates/aifi-core/src/types.rs`：如需新增字段，保持 `serde` 兼容。
- `crates/aifi-harness/src/{lib,fixtures}.rs`：新增 `FakeVolume::hardlink`、`move_dir`、批量生成器 `synthetic(n)`。
- `crates/aifi-harness/tests/`：新增测试文件；`benches/`（可选，criterion 需先在 PR 中说明）。

## 接口（保持/新增）
```rust
impl StringArena { pub fn compact(&mut self, live: impl Iterator<Item = &mut NameRef>); }
impl VolumeIndex {
    pub fn compact(&mut self);                       // 删除标记节点、整理 arena；NodeId 可变，FRN 映射同步更新
    pub fn memory_usage(&self) -> MemoryStats;       // 新增，供 index_status
    pub fn children(&self, id: NodeId) -> impl Iterator<Item = NodeId>; // 供 list_project_tree（可先 O(n)）
}
pub fn synthetic(n: usize, seed: u64) -> FakeVolume;  // aifi-harness
```

## 验收标准 / 测试
- [ ] 乱序插入（子先于父、父后到）后全路径正确；父缺失时 `full_path` 返回 `None` 而不是 panic。
- [ ] 父链成环（损坏数据）不会死循环。
- [ ] 重命名目录后，所有后代路径更新；删除目录后后代不可见。
- [ ] `compact()` 前后：所有存活节点的 `full_path` 完全一致（性质测试：随机操作序列 1 万步）。
- [ ] `synthetic(2_000_000)` 构建 < 3 s（release），`memory_usage` < 200 MB，在 PR 中贴实测数据。
- [ ] 硬链接行为有测试并写入文档注释。
- [ ] `cargo fmt`、`clippy -D warnings`、`cargo test` 全绿。

## 不在范围内
NTFS 读取（M2）、USN（M3）、快照文件格式（M3）、拼音与查询（M4）、任何 IO。

## 审查清单
- [ ] `aifi-core` 仍然没有 IO / 平台依赖
- [ ] 库代码无 `unwrap()` / `expect()`（测试除外）
- [ ] 所有上限（深度、arena 4 GiB）有错误返回而非 panic
- [ ] PR ≤ ~400 行（可拆成 arena / index / harness 三个 PR）
- [ ] 遵守 AGENTS.md 安全红线
